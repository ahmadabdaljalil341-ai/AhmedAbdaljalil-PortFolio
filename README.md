# Ahmed — Portfolio website

نسخة مستقلة من أحدث بورتفوليو، تشمل واجهتي الكمبيوتر والهاتف.
الموقع Static: HTML + CSS + JavaScript. لا يحتاج npm أو عملية build أو مفاتيح API.

## الملفات

- `index.html`: الأقسام، التعريف، المهارات، الخبرات وبيانات التواصل.
- `style.css`: الألوان والتنسيق وواجهة الهاتف والحركات.
- `projects.js`: أسماء المشاريع والصور وروابط المواقع وترتيبها.
- `app.js`: الجاليري والتنقل ومعاينة اللوجوهات.
- `assets/`: الصور واللوجوهات وأيقونات البرامج وملف الـCV الأصلي.
- `.nojekyll`: لتقديم الملفات مباشرة على GitHub Pages.

## معاينة على جهازك

افتح `index.html` في المتصفح. ويمكن أيضًا تشغيل خادم محلي من داخل المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## رفع النسخة إلى GitHub

1. فك ضغط الملف.
2. أنشئ Repository جديدًا في حسابك، باسم مثل `ahmed-portfolio`.
3. ارفع **محتويات** مجلد `ahmed-portfolio`، بحيث يكون `index.html` في جذر المستودع، وبجانبه مجلد `assets` كاملًا. لا ترفع ملف ZIP نفسه كموقع.
4. من Settings → Pages، اختر Deploy from a branch، ثم `main` والمجلد `/(root)`، واضغط Save.
5. افتح رابط الموقع الذي يظهر في Pages بعد اكتمال النشر.

[دليل GitHub Pages الرسمي](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## ربط دومين شخصي لاحقًا

لا يوجد دومين افتراضي مفروض في الملفات.

1. في Settings → Pages، أضف الدومين في Custom domain واحفظه أولًا.
2. عند شركة الدومين، أضف سجل CNAME للاسم `www` يشير إلى `USERNAME.github.io`، واستبدل USERNAME باسم حسابك، من غير اسم المستودع.
3. للدومين بدون www، أضف سجلات A الأربعة التالية للاسم `@`:

| Type | Name | Value |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |

4. انتظر فحص DNS ثم فعّل Enforce HTTPS عندما يتاح. إعدادات DNS قد تستغرق حتى 24 ساعة.
5. احتفظ بملف CNAME الذي ينشئه GitHub ضمن نسخك اللاحقة.

[دليل الدومين الرسمي وتحديثات DNS](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)

## استضافة أخرى

يمكن رفع المحتويات إلى مجلد الموقع على أي استضافة تدعم الملفات الثابتة. البداية هي `index.html` في الجذر. احتفظ بمجلد `assets` وبنفس أسماء الملفات؛ المسارات نسبية وتدعم الدومين الشخصي ومسار مستودع GitHub Pages.

## التعديل وإضافة أعمال

عدّل بيانات المشروع في `projects.js`. ضع الصور الجديدة في `assets` واكتب أسماءها داخل قائمة `images`. حدّث `imageRatios` بنسبة عرض كل صورة إلى ارتفاعها؛ مثال 1600×900 = 1.7778. للحفاظ على التكوين، استخدم أسماء إنجليزية بلا مسافات، ولا تغيّر IDs الموجودة إذا أردت بقاء الروابط المباشرة للمشاريع.

صور العلامات تظل بالتصميم الأصلي؛ أسماء العرض الحالية هي Nova وJad Al Masadir. ملف الـCV داخل assets هو الأصل المرفوع. نسخة التصدير لا تحتوي بيانات دخول أو سجل Git أو إعدادات استضافة ChatGPT.

تم فحص بنية الحزمة والملفات وصياغة JavaScript. هذه النسخة لم تُرفع إلى حساب GitHub أو تُربط بدومين بعد، ولم يتم اختبارها فعليًا على كل الأجهزة. شراء الدومين وتجهيز الحساب يتمان بشكل منفصل.
